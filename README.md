# Guida di riferimento HTML

Guida personale di riferimento dedicata ai principali elementi e concetti di HTML5.

Il progetto nasce come strumento di studio e consultazione, raccogliendo teoria, esempi pratici e annotazioni personali realizzate durante l'apprendimento di HTML.

L'obiettivo è avere un riferimento pratico da poter consultare e aggiornare nel tempo, utilizzando direttamente il codice come parte del processo di apprendimento.

## Contenuti

La guida raccoglie diversi argomenti fondamentali di HTML5:

* Elementi HTML di base
* Intestazioni e paragrafi
* Formattazione del testo
* Citazioni
* Liste ordinate, non ordinate e di definizione
* Link e collegamenti
* iframe e contenuti esterni
* Immagini
* Immagini raster e vettoriali
* SVG
* Immagini responsive
* Video
* Tag HTML semantici
* Tabelle
* Form HTML
* Tipi di input
* Textarea
* Datalist
* Label
* Select
* Button
* Fieldset e Legend
* Principali attributi degli input

## Funzionalità

* Navigazione tra le diverse sezioni della guida
* Esempi pratici direttamente visualizzabili nella pagina
* Esempi di codice HTML
* Dark Mode
* Collegamenti a risorse esterne
* Video incorporati tramite iframe
* Layout responsive
* Navigazione rapida verso l'inizio della pagina

## Tecnologie utilizzate

* HTML5
* CSS3
